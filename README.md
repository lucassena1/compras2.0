# Lista de Compras — versão estática

Esta versão abre diretamente na Vercel, sem Postgres, Neon ou Vercel Blob.

## Publicação
Envie para a raiz do repositório:
- index.html
- vercel.json
- pasta encartes/

Não é necessário configurar variáveis de ambiente.

Os três encartes atuais e o comparativo inicial estão pré-carregados. Marcações e novos itens são armazenados no localStorage do navegador.

Para análise automática de novos PDFs e persistência entre dispositivos, será necessário reativar a versão com backend posteriormente.
